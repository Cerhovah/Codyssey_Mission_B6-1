# SQLite 실행 캡처

새 연습용 DB에서 SQLite CLI 3.43.2를 실행하고, 터미널 세션이 내보낸 명령과 결과를 구간별로 이미지에 담았습니다. 시스템 화면을 캡처할 수 없는 환경이라 터미널 세션 출력을 이미지로 저장했습니다. [핵심 실행 텍스트](../01_queries.txt) · [보너스 실행 텍스트](../02_bonus.txt)

| 쿼리 | 무엇을 볼 수 있나요? |
| --- | --- |
| [Q01–Q04](01-q01-q04.png) | 데이터 준비, 소설 세 권, 제목 검색, 최신 회원, 11월 대여 |
| [Q05–Q07](02-q05-q07.png) | 미반납 회원과 도서, 도서별 분류, 대여가 없는 회원 뒤의 `NULL` |
| [Q08–Q09](03-q08-q09.png) | 기한 뒤 반납한 도서, 김하늘의 대여 5건과 신나연·조하진의 0건 |
| [Q10–Q12](04-q10-q12.png) | 도서별 대여 일수의 합계와 평균, 대여가 없는 두 회원 |
| [Q13–Q15](05-q13-q15.png) | 반납일 변경, 삭제 뒤 0행, 인덱스가 적용된 열 |
| [B01A–B04](06-b01-b04.png) | 두 가지 조회 결과와 월별 대여·인기 도서·미반납 연체 |
| [B05와 최종 검사](07-b05-integrity.png) | 외래키 오류, 수정 입력과 롤백, 대여 원상복구와 무결성 검사 |

같은 출력을 보려면 [재현 문서](../../../reproduction.md)의 1단계에서 표와 샘플을 만든 뒤 아래 설정으로 바꾸고 2단계로 넘어갑니다. `.echo on`은 파일에 들어 있는 SQL도 함께 표시합니다. 3단계의 첫 조회는 핵심 실습 뒤 복원된 두 대여를 보여 줍니다.

```text
.mode list
.separator " | "
.nullvalue NULL
.bail off
.echo on
```
